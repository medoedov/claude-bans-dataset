# Окружение, клиент и сочетание признаков

База: россияне и китайцы с известным исходом — 1025 историй, забанены или временно заблокированы 730 из 1025 (71%).
Доля банов — среди рассказавших, сравнивать можно только строки между собой (см. method.md). p — точный тест Фишера.

## 2. Складываются ли признаки риска

Признаки: Max 20x, чужие деньги, аккаунт младше месяца, IP меняется, несколько аккаунтов. Считаются истории, где названо не меньше двух признаков из набора; признак, который не назван, не считается ни риском, ни его отсутствием.

| Набор признаков | Историй | Ни одного | Один | Два и больше | p (0 против 2+) |
|---|---|---|---|---|---|
| Max 20x, чужие деньги, аккаунт младше месяца, IP меняется, несколько аккаунтов | 458 | 66 из 121 (55%) | 145 из 228 (64%) | 74 из 109 (68%) | 0.04 |
| чужие деньги, IP меняется, несколько аккаунтов | 197 | 39 из 79 (49%) | 44 из 83 (53%) | 20 из 35 (57%) | 0.54 |

- на Max 20x, по числу остальных признаков: 0 — 41 из 46 (89%); 1 — 26 из 36 (72%); 2+ — 3 из 5 (60%)
- не на Max 20x, по числу остальных признаков: 0 — 33 из 54 (61%); 1 — 53 из 98 (54%); 2+ — 19 из 29 (66%)
