# Российский фокус: истории, связанные аккаунты и новые свидетельства

6 ноября 2026. Для второй статьи выделен отдельный рабочий срез из [v2](../../v2/README.md): **767 аккаунтных историй для проверки российского контекста**, 250 дополнительных наблюдений, 457 событий и 225 ссылок из расширения. Публичные ссылки старых историй также находятся в самих строках `ru-candidates.csv`.

Это включает все 760 строк прежней группы RU, пять историй с российскими документами из WORLD, связанную работающую замену `v2-0290` и языковой кандидат `github-059`. Старая группа RU определялась в том числе площадкой, поэтому 767 не означает 767 подтвержденных граждан России. В `membership.csv` видны отдельные основания: записанное местонахождение, документ, текст, группа источников или связь с другим аккаунтом.

## Файлы

| Файл | Содержание |
|---|---|
| ru-candidates.csv | Полные исходные строки кандидатов с прежними case_id |
| membership.csv | Основания включения и известная коррекция |
| details.csv, events.csv, sources.csv | Все связанные наблюдения, события и ссылки из v2 |
| selection-summary.json | Размеры, состав и SHA256 четырех входных файлов |
| new-evidence.json | 12 новых материалов для разметки: отдельные аккаунты, серии владельцев и возможные продолжения |
| followups.json | Новый ответ по существующей API-апелляции v2-0166 |
| poll-aggregate.json | Округленный результат одного опроса в русскоязычном чате |
| select_ru.py, test_select_ru.py | Отбор и 10 проверок |

**12 материалов не равны 12 новым аккаунтам.** Один материал может описывать три аккаунта или несколько неразличимых регистраций. Совпадения с прежней базой и российское происхождение части авторов еще проверяются. Новые материалы не прибавлены к счетчику v2.

## Что добавляет этот сбор

В одном первичном рассказе сохранена цепочка трех аккаунтов: бан и отказ апелляции; новая регистрация, принятая проверка паспортом РФ, оплата апгрейда и повторный бан; следующая регистрация Pro и работа. У других владельцев отдельно записаны повторные баны, возрастные ограничения и успешные проверки. Запрос KYC, принятый документ, возрастное ограничение и полная блокировка остаются разными состояниями.

Новый комментарий по `v2-0166` меняет знание об апелляции: кнопка появилась, заявление подано, получен отказ. Это продолжение API/организации, а не новый потребительский аккаунт.

В опросе, созданном 30 октября, участвовало **около 70 человек** по уточнению автора исследования. На предоставленном снимке: 10 отметили бан, 32 отсутствие бана, 15 запрос KYC, 17 не пользуются Claude. Выбранных ответов 74; категории не рассматриваются как взаимоисключающие группы. Это срез одного русскоязычного сообщества, не национальная частота блокировок. Анонимные ответы не прибавлены к аккаунтным историям. Сырой снимок с аватарами не публикуется.

## Как повторить отбор

Зависимости — стандартный Python 3. Входы: четыре CSV из `v2/`. Из каталога этого приложения:

```sh
python test_select_ru.py
python -c "from pathlib import Path; import select_ru; select_ru.INPUT = Path('../../v2'); select_ru.main()"
```

Скрипт включает связи `related_case_ids` в обе стороны и транзитивно, чтобы работающая замена не исчезала только потому, что в ее аннотации не повторили страну. Российская связь не передается по этим связям как установленное гражданство: сохраняется лишь основание кандидатного отбора.

У `v2-0034` прежняя разметка страны документа ошибочна. Исходные поля сохранены для истории, но документный и текстовый RF-флаги этой строки не используются; исправление явно записано в `membership.csv`. Частные экспорты, имена из них, внутренние идентификаторы и изображения документов не публикуются.

Отбор прошел red team, code review и test review. Новые описания проверены отдельно: принадлежность паспорта не додумывается, планы регистрации не считаются состоявшимися аккаунтами, истории одного владельца не считаются независимыми людьми.
