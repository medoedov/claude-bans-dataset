# Кого банят в Claude: 1692 историй

Датасет к статье на Хабре «Я собрал 1692 историй банов Claude. Кого банят и почему» [ссылка — после публикации].

1692 историй с одиннадцати площадок: Reddit, GitHub, Hacker News, X, Хабр, vc.ru, DTF, Pikabu, Telegram, V2EX и linux.do. В каждой человек рассказывает о своем аккаунте Claude: тариф, способ оплаты, тип выхода в интернет, возраст аккаунта, интенсивность использования, язык общения с Claude и что с аккаунтом стало. В 1268 историях аккаунт забанили, в 317 он пережил волну. Период — январь 2025 — 7 октября 2026.

| Файл | Что внутри |
|---|---|
| `cases.csv` | истории, одна строка — один аккаунт; колонка `group` — RU, CN (Китай и Гонконг) или WORLD |
| `schema.md` | что значит каждая колонка и как размечалось |
| `method.md` | источники, группы, как читать доли, ограничения, профиль волны 1 октября |
| `groups.py` | расчет таблиц и теста Фишера: `python groups.py` |
| `results/` | результат расчета: `groups.md` и график |
| `theories/` | какие причины бана называют сами пользователи: Россия, Китай, остальной мир |

Главное ограничение: это истории тех, кто решил рассказать. Доля банов в таблицах считается среди рассказавших и не равна вероятности бана. Строки одной таблицы при этом сравнимы между собой. Подробнее — в `method.md`.

Ники авторов не записаны. Ссылки ведут на публичные посты; у 34 историй из закрытого Telegram-чата ссылок нет.
